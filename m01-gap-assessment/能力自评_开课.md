## 三个重点（并列 2 分项的取舍）

有五项并列 2 分，按「不补会不会卡住其他项」排序，圈出这三项：

| 重点 | 为什么是它 | 目标分（8 周后） |
|---|---|---|
| **Python 工程化**（M2） | 后续所有交付物的载体，不解决它，M2–M9 每个产出都会变形 | 4 |
| **LLM API 应用开发**（M3） | FDE 的核心价值输出，客户付钱买的就是这个 | 4 |
| **理解企业业务与 ROI**（M4） | 决定方向对不对；技术做对了但商业上没价值等于零 | 3 |

三项分别对应：能不能做出来 → 做的东西有没有用 → 值不值得做。

## 第二梯队（跟着课程走会自然提升）

- **Git 协作**：M2 每次提交都会练到，配合 PR 流程即可从 2 到 3
- **API 服务与容器化**：M2 的主要产出，做完必到 3–4
- **职场写作**：M8 专项，但每次模块报告都是练习机会

## 已有优势（要放大，别丢）

- **对外演示与汇报 4 分**：全场最高。FDE 是 customer-facing 岗位，这是比同届 AI 硕士强的地方。作品集 README 和面试自我介绍都要往前放这一条。
- **评测设计 3 分**：研究训练留下的底子，M7 会把它变成优势——大多数工程背景的候选人这块反而弱。
