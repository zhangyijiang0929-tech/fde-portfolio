# 综合实战 Capstone

**放什么**：端到端项目 + Case Study + 复盘。
**讲义对应**：M9（青禾剧本或真实小客户，评分权重、作品集包装、复盘）

**状态**：未开始

**完成判据**

- 从发现到交付走完一遍，每个阶段都有产出物
- Case Study 按「问题 → 判断 → 做法 → 结果」组织，不按技术栈组织
- 复盘里有「我以为 X，实际是 Y」的段落
- 别人能按 README 从零跑起来

## Case Study 骨架

1. 客户是谁、什么场景、卡在哪（一句话）
2. 为什么选这个方案，为什么排除别的
3. 怎么验证有效（数字 + 基线对比）
4. 交付了什么、留下了什么
