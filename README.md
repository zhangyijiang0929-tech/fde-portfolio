# 张奕疆 · FDE 作品集

> 一句话：AI 硕士，正在把研究能力转成能独立交付的工程项目能力。

## 我是谁

AI 方向硕士在读，研究方向偏算法与实验设计。目前在系统补齐正向部署工程师（Forward Deployed Engineer）需要的能力：把客户的模糊需求变成能运行、能量化、能维护的系统，而不只是跑出一个指标。

强项是**对外演示与汇报**（能把技术讲给非技术听众）和**评测设计**（知道怎么证明一个方案真的有效）。正在补的是工程交付的完整链条。

开课自评里最低的三项（均 2 分），也是这 8 周真正要解决的问题：

3. **理解企业业务与 ROI** —— 决定做的事值不值得
